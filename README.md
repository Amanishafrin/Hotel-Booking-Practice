React Hotel Booking Practice
## About This Project
  This is a beginner-friendly project created to practice React concepts. It uses some hooks and displays five hotels. Users can easily increase and decrease the room count and each hotel has its own room limit.
  ## Features
1. Displays five hotels using dynamic data.
2. Navigate to individual hotel detail pages.
3. Increase and decrease room counts for each hotel.
4. Each hotel has its own room availability limit.
5. Displays alert messages when the room limit is reached.
6. Uses reusable React components.
## React Concepts Practiced
   useState() – Manages room counts for each hotel.
   useParams() – Gets the hotel ID from the URL.
   useNavigate()– Navigates between pages.
   fill()– Fills an array with the same initial value.
   Spread Operator (...)– Copies array values and creates a new array.

  ## Purpose
   Created as a practice project to learn React fundamentals and React Router navigation.
